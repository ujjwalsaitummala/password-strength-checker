      Best practices
      

      🔑
      Master password strength
      Use a long passphrase: 16+ characters or 6+ random words. Never reuse it anywhere else.
      

      💾
      There is no recovery
      Your master password cannot be reset. Keep an encrypted backup offline and test it with "Verify a backup file".
      

      💻
      Device security
      Use a screen lock, keep your system and browser updated, lock the vault when you step away, and avoid shared or public devices.
      

      🔄
      Password hygiene
      Use a unique password for every account, turn on multi-factor login, and change important passwords regularly.
      

      🎣
      Phishing
      Check unfamiliar links before you log in. Never enter your vault master password on any website other than this app.
      

      Remember: your master password is the only way to open your vault. Keep it safe and never share it.
      

      Link check
      

      Paste a web address before you log in. The check runs on this device and sends nothing. It spots common tricks, but it can never prove a site is safe.
      

      

      Security activity
      

      A timeline of what happened in your vault. It is stored inside the encrypted vault on this device and lists site names, never passwords.
      

      

      Privacy and data
      

      Everything this app stores lives in this browser. The only optional external request is the breach check, which sends a 5-character SHA-1 hash prefix, not your password.
      

      Stored on this device
        

        What contacts the internet
          


        • Breach check (only when you click): sends the first 5 characters of a SHA-1 hash of a password, plus padding, to api.pwnedpasswords.com. The password and full hash never leave your device.
          • 

        • Checker, generator, link check, audit, learning mode and the vault run entirely on this device.
          • 

        • The offline service worker caches this app's own files. There is no analytics, advertising or tracking.

        Deleting is permanent. Without a backup file and its backup password, deleted passwords cannot be recovered.
